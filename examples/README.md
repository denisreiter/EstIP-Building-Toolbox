# Example workspace

This `.gpkg` includes a small, partly fictional data example. It executes the full pipeline from s1 - s6.

To use this, change the `workspace` parameter inside `examples/configs/` for each script (cfg_s1.yaml to cfg_s6.yaml) to point to `example_workspace.gpkg`.

Additionally, change `lod2_functions_table` to point to the `lod2_2022_residential_functions.csv` provided in `examples/`.

Field names are setup to be plug-and-play.
